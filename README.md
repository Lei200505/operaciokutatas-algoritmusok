# Operációkutatás algoritmusok

## Kétfázisú szimplex algoritmus
Lineáris programozási feladatot old meg, kétfázisú szimplex módszerrel. Első fázisban egy kezdeti bázismegoldást keres. A második fázisban az optimumot határozza meg, valamint felismeri a megoldhatatlan és korlátlan eseteket.

## Szintező algoritmus
A szintező algoritmus egy konkrét feladatra való implementációja. Egy irányított gráfnak keres megfelelő irányítását, hogy a megfelelő csúcskorlátoknak megfeleljen. Az algoritmus élek megfordításával és csúcsszintek módosításával keres megfelelő orientációt, illetve meghatározza a hibás esetekben a sértő csúcshalmazt.
